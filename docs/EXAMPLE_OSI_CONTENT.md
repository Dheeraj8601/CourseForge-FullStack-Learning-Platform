# Example OSI course authoring

Create a free course named **Understanding the OSI Model**, with passing score 70%, SkipQuizzes off. Add these seven pages in order:

1. Physical Layer — Bits, cable/wireless signals, hubs, repeaters. Quiz: Which unit does Layer 1 carry? Options: [Frames, Bits, Packets, Segments], correct index: 1.
2. Data Link Layer — Ethernet frames, MAC addresses, switches. Quiz: Which identifier is used at Layer 2? Options: [IP, MAC, Port, URL], correct index: 1.
3. Network Layer — Routers, IPv4/IPv6, packet forwarding. Quiz: Which device routes packets? Options: [Router, Hub, Repeater, Keyboard], correct index: 0.
4. Transport Layer — TCP/UDP, ports, reliability. Quiz: Which protocol is connection-oriented? Options: [UDP, ICMP, TCP, ARP], correct index: 2.
5. Session Layer — Establish, maintain and terminate communication sessions. Quiz: Which layer manages sessions? Options: [Transport, Session, Physical, Network], correct index: 1.
6. Presentation Layer — Encoding, compression, encryption. Quiz: Which layer is associated with data representation? Options: [Presentation, Network, Physical, Transport], correct index: 0.
7. Application Layer — HTTP, DNS, SMTP and user-facing network services. Quiz: Which protocol is used to request web pages? Options: [HTTP, ARP, IP, Ethernet], correct index: 0.

Use the course's `SkipQuizzes` flag when you want quiz-free reading courses. For each lesson create one or more multiple-choice questions in Admin studio.
